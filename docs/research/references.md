# 연구 참고자료

아래는 이전 대화에서 참조한 1차 논문·개발자 자료의 목록이다. 이번 저장소 초기화 과정에서 체계적 문헌고찰이나 원문 전체 재검토를 수행한 것은 아니다. 문헌이 존재한다는 사실만으로 본 서비스 모델·문항·예측이 검증된 것으로 표시하지 않는다. 척도 사용 조건과 한국어판 근거는 적용 시 확인해야 한다.

| 영역 | 자료 | 검토 용도 |
|---|---|---|
| 대인원형 | [Markey & Markey, IPIP-IPC 채점 자료](https://ipip.ori.org/newIPIP-IPCScoringKey.htm) | Agency·Communion과 여덟 영역의 구조 비교 |
| 대인원형 | [Locke, Interpersonal Circumplex Models and Measures of Personality](https://kennethlocke.org/publications/2023_Interpersonal_Circumplex_Models_Measures_of_Personality.pdf) | 동기·행동 등 측정 면의 구별 검토 |
| 대인행동 관찰 | [Hopwood et al., CAID 연구](https://pubmed.ncbi.nlm.nih.gov/30221975/) | 실제 dyad 행동·맥락·상보성 검토 |
| 애착 | [Fraley, ECR-RS 개발자 자료](https://labs.psychology.illinois.edu/~rcfraley/measures/relstructures.htm) | 일반 및 상대별 불안·회피 측정 |
| 자율성 | [SDT, GCOS](https://selfdeterminationtheory.org/general-causality-orientations-scale/) | 일반 동기 지향성 비교 |
| 관계 동기 | [SDT, SRQ](https://selfdeterminationtheory.org/self-regulation-questionnaires/) | 특정 관계의 자발적·통제된 동기 |
| 자율성 정의 | [Chirkov et al., 2003](https://pubmed.ncbi.nlm.nih.gov/12518973/) | 자율성과 독립성·개인주의 구별 |
| 정서조절 | [Gross & John, 2003](https://pubmed.ncbi.nlm.nih.gov/12916575/) | 재평가와 표현 억제 전략 |

| 공동조절 | [Butler & Randall, 2013](https://doi.org/10.1177/1754073912451630) | 두 사람 사이의 시간적 조절 과정 |
| 상호의존 | [Rusbult & Van Lange, 2003](https://doi.org/10.1146/annurev.psych.54.101601.145059) | 상황 구조와 관계 과정 |
| Dyadic coping | [DCI 중국 커플 검증 연구](https://pubmed.ncbi.nlm.nih.gov/27183045/) | 자신의 행동·상대 행동·공동 대처 구별 |
| 관계 결과 | [Funk & Rogge, 2007, CSI](https://pubmed.ncbi.nlm.nih.gov/18179329/) | 관계만족을 별도 결과로 측정하는 비교 후보 |
| APIM | [Kenny, Dyadic Analysis](https://davidakenny.net/dyad.htm) | actor·partner 효과·상호작용 구별 |
| 표본 설계 | [Pair Laboratory 연구 자료](https://labs.utdallas.edu/pairlab/research-materials/) | APIM 검정력 검토 도구 |
| 유사성 검증 | [Schönbrodt et al., 2018](https://doi.org/10.1002/per.2169) | Dyadic response surface analysis |
| MBTI 비교 | [McCrae & Costa, 1989](https://pubmed.ncbi.nlm.nih.gov/2709300/) | MBTI와 일반 성격 차원의 관계·한계 |

| 척도 이용 | [Stanford Psychophysiology Laboratory 자료](https://spl.stanford.edu/resources) | 정서조절 도구 및 사용 범위 확인 |

## 향후 Evidence Map 양식

문헌 ID, 구성개념, 정의, 이론 전통, 개인·관계·상황 수준, 대상·문화, 측정도구, 결과변수, 연구설계, 효과와 불확실성, 재현 여부, 한계, 모델 포함·보조·제외의 잠정 판단을 기록하는 안이다. 아직 실제 추출을 수행한 표는 아니다.
