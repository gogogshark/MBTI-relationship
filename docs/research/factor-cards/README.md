# 6팩터 근거 카드

연구 1단계 산출물이다([연구 계획](../research-roadmap.md) 4장). 팩터별로 정의, 원 연구, 후속 연구, 관계에서의 모습, MBTI·Big Five와의 연결, 조합 근거를 정리한다.

- 각 카드의 서지는 확인 상태(원문 확인 / 초록 확인 / 미확인)를 함께 적는다.
- 작성 에이전트와 다른 에이전트가 서지·수치를 원문과 대조한 결과를 카드 끝 "검증 기록"에 남긴다.
- 원척도 전체 문항은 싣지 않는다.

## 1단계 결과 요약 — MBTI 연결 강도(제안)

A = 직접 근거, B = Big Five 경유, C = 약함. 다섯 카드 모두 MBTI와 팩터를 직접 연결한 연구는 찾지 못했다. 그래서 A는 없다.

| 팩터 | B | C | 서비스 처리 제안 |
|---|---|---|---|
| Agency | E–I(외향성 경유) | S–N, J–P | 유형 기반 수준 표시 가능, 단정 금지 |
| Communion | T–F(우호성 경유, B~C) | S–N, J–P | 유형 기반 수준 표시 가능, 단정 금지 |
| 애착불안 | — | 전 차원(신경증과 주로 관련) | "개인차가 큰 영역", 필요 시 약식 문항 |
| 애착회피 | E–I(B~C) | 나머지 | "개인차가 큰 영역" 위주 |
| Autonomy | E–I, S–N(외향성·개방성 경유) | T–F, J–P | P를 자율성으로 읽지 않음(독립성과 혼동 방지) |
| Regulation | E–I(억제와 역상관) | 나머지 | "개인차가 큰 영역" 위주 |
| Coordination | — | 전 차원 | 수준 없음. 두 사람·상황에 따라 달라지는 영역으로 설명 |

교차 검증(V1) 결과: 다섯 카드에서 불일치 14건을 찾아 본문에 반영했다. 미확인으로 남은 서지는 각 카드 9장에 있다.
