# 연구 방법 제안 보관

**상태: 이전 제안 보관.** 2026-10-16 연구가 재개되었다(D-009). 현재 제안은 [연구 로드맵](research-roadmap.md)을 기준으로 한다. 이 문서는 이전 제안을 보존하며, 수행 승인·모집 계획·확정 연구 프로토콜을 뜻하지 않는다.

## 구별할 연구 과제

1. 유형 추정: 추가 응답과 유형·성향 후보의 연결 및 재현성.
2. 관계 팩터 측정: 정의에 맞는 내용, 구조, 신뢰도, 판별타당도.
3. 관계 분석: actor·partner 효과, 사전 지정한 조합효과, 후속 결과 예측.
4. 솔루션 효과: 제안 실행과 관계 결과의 변화 및 비교 조건 대비 효과.

설명이 마음에 든다는 평가는 사용성 자료이지, 예측 정확성의 충분한 근거가 아니다. 입력 MBTI를 예측값의 입력과 정답으로 동시에 사용해 정확도를 산출하지 않는다.

## 이전에 제시한 단계와 예시 규모

아래 숫자는 예산·모집 규모를 가늠하기 위한 예시일 뿐, 충분한 표본을 보장하는 기준이 아니다. 효과크기·모형·탈락률 등을 고려한 검정력 검토가 필요하다.

| 단계 | 내용 | 예시 목표 |
|---|---|---|
| 이론 정리 | 20~30개 개념의 중복·차별성·측정 수준·예측 근거 비교 | Evidence Map |
| 인지면접 | 문항 이해와 응답 과정 검토 | 약 20~30명, 반복 수정 |
| 운영 파일럿 | 문항 부담·결측·중단·수집 오류 점검 | 약 80~120명 |
| 척도 개발 | EFA, 내용 검토, 기존 척도 비교 | 약 300~500명 |
| 독립 확인 | 별도 표본 CFA·재검사·간이형 검증 | 약 300~500명 |
| 관계 연구 | 양측 응답·맥락·후속 결과 | 약 250~400쌍을 초기 모집 목표로 검토 |
| 솔루션 평가 | 실행·변화·비교 조건 | 별도 설계 필요 |

문항은행 70~100개 등의 출발안, 간이 관계 문항 12~18개, 심화 관계 문항 30~40개, 관계 모듈 12~20개는 모두 이전의 사용성·개발 가정이다. 함께 확정된 검사지 구성이 아니며 실제 요인 수에 따라 수정한다. 유형 추정 문항의 분량은 별도다.

## 수집 구조 제안

- 개인의 일반 패턴과 특정 상대·사건의 응답을 구별한다.
- 사용자 자기보고, 상대 관찰, 상대 직접 응답에 출처를 붙인다.
- 같은 사람의 같은 행동에 대한 자기보고와 상대보고를 비교한다. A의 자기점수와 B의 자기점수 차이를 곧 인식 차이로 부르지 않는다.
- 관계 결과는 팩터 문항과 구분하고, 가능하면 리포트 노출 전 기준 상태를 받는다.
- 결과 노출·솔루션 종류·시점도 기록해 후속 응답의 영향을 검토한다.
- 무료·유료 이용자, 초대 완료·미완료 등 선택 편향을 검토한다.

## 데이터 항목 초안

| 묶음 | 예시 |
|---|---|
| 참여·동의 | 가명 ID, 동의 범위·버전, 철회 상태 |
| 관계 | 관계 ID, 양측 가명 ID, 종류, 연결 동의 |
| MBTI | 입력 유형, 출처·시점, 확신 정도 |
| 응답 | 문항 ID·버전, 원응답, 대상, 기준 기간, 응답 시각 |
| 결과 | 채점·모델 버전, 하위 점수, 불확실성 |
| 노출 | 제공 리포트·솔루션과 시각 |
| 후속 | 만족·갈등 부담·행동 실행·변화 |
| 이용 | 중단·완료·초대·결제·열람 상태 |

실제 참가자 데이터는 이 공개 저장소에 저장하지 않는다. 연락처·결제정보와 연구 응답을 분리하는 안이며, 동의·보관·삭제 정책은 별도 설계가 필요하다.

## 분석 시 유의할 점

- 척도 내용·EFA/CFA·신뢰도·측정오차·판별타당도와 예측 가중치 검증을 구별한다.
- APIM은 actor·partner 효과를 구분하는 틀이다. 조합효과는 별도로 모형에 넣어 검토한다.
- 유사성은 차이 점수만으로 단정하지 않고, 필요하면 다항회귀·반응표면분석을 검토한다.
- 개발·평가 자료를 사람·관계 단위로 나누고 반복 참여·연결된 dyad의 누출을 방지한다.
- 간이·심화의 겹치는 문항 때문에 상관이 높아지는 효과를 검토한다.
- 성별·연령·관계유형의 측정동일성과 적용 범위를 검토한다.
- MBTI-only, 독립 Factor, 맥락, 양측 자료 등의 추가 설명력을 비교하는 안이다.
- 16×16 궁합표나 고정된 유형별 Factor 점수부터 확정하지 않는다.

## 후속 측정 제안

최초 결과 노출 전 기준 상태, 일부 표본의 2~4주 재검사, 솔루션 7일 실행 확인, 약 30일 변화, 일부 90일 지속성을 검토하는 안이 있었다. 확정 일정이나 예약 발송 요청이 아니며, 자동화는 생성하지 않는다.

## 재논의할 미정 사항

연구 책임·검토 체계, 척도 사용 권한·한국어판 근거, 대상·제외 기준, 정확한 표본·분석계획, 실패·중단 기준, 보호·동의 정책, 통계 검토, 솔루션 비교 조건을 정해야 한다.
