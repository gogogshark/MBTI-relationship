# 현재 상태

기준일: 2026-10-16 (Asia/Seoul)

## 현재 범위

- 기획·결정사항·연구 기록을 GitHub에 정리하고 향후 코드 개발과 함께 관리한다.
- 연구를 먼저 진행한다(D-009, 2026-10-16). 서비스 논의는 뒤로 미룬다.
- 서비스는 유형 기반 정보 제공 서비스로 본다(D-011). 서비스 문서 반영은 서비스 논의 재개 시 한다.
- 연구 로드맵 제안: [연구 로드맵](research/research-roadmap.md). 연구는 AI 에이전트가 수행하고 교차 검증 구간을 둔다(D-014). 신규 표본조사 없이 기존 자료·연구 결과를 활용하고, 출시 뒤 누적 데이터로 보완한다(D-015). 유형 자료는 사용자 제공 영상·스크립트, 6팩터 근거는 학술·후속 연구를 쓴다(D-016).
- 앱 코드, 운영 서비스, 결제 연동, 실제 검사 문항·채점, 배포 환경은 구현하지 않았다.

## 사용자 명시 사항

1. 본인 검사 뒤 간단 분석을 제공한다.
2. 원하는 상대 정보를 입력하거나 상대 관련 간이검사를 진행한다.
3. 분석을 준비한 뒤, 유료 결과 열람 전에 결제를 유도한다.
4. 정보 단계에 따라 4,900~9,900원이다.
5. 결과 열람 뒤 심화 정보를 원하면 앞서 결제한 비용을 제외한 금액을 추가 결제한다.
6. 기획·결정·연구와 코드 개발을 이 저장소에서 함께 관리한다.
