# 서비스 개요

## 목적과 제공 가치

한국 사용자를 대상으로 개인의 관계 행동과 특정 상대와의 상호작용을 설명하고, 실제 상황에서 사용할 수 있는 대응 방법을 제공하는 유료 웹 서비스를 기획한다.

MBTI는 자기인식에 관한 보조 정보와 진입 인터페이스로 활용한다. 서비스의 중심은 독립적인 관계심리 모델이다. 유형별 상투적 설명이나 검증되지 않은 궁합표보다, 상황·상대·행동을 연결하는 해석을 지향한다.

예시 방향: 갈등을 빨리 해결하려는 행동이 상대에게 어떻게 받아들여지는지, 감정 확인과 해결 제안의 순서를 어떻게 조정할 수 있는지 설명한다. 이러한 문구 자체는 검증된 개인 예측이 아니다.

## 검토 중인 관계 범위

- 연애
- 배우자
- 친구
- 직장동료 및 역할 관계

이 목록은 서비스 기획 범위다. 각 관계에 대한 측정동일성·예측타당성이 확인되었다는 뜻은 아니다.

## 사용자 입력 후보

- 본인 MBTI와 모름·불확실 선택
- 본인 추가검사
- 필요한 최소 배경정보
- 상대 MBTI 또는 상대 행동에 대한 사용자 관찰
- 관계 종류와 관계 경험
- 선택적으로 상대의 직접 참여·응답 연결

입력 MBTI, 자체 추정 후보, 독립 관계 팩터는 구별한다. 사용자가 상대를 평가한 자료를 상대의 직접 응답으로 취급하지 않는다.

## 결과 제공 구조

1. 본인 검사 후 무료 간단 분석.
2. 상대 입력·검사 후 제공 항목과 가격 안내.
3. 유료 결과 열람 전 결제.
4. 결제한 정보 단계의 관계 해석·대응 방법 제공.
5. 선택 시 차액 결제로 심화 결과 확장.

웹 열람을 기본으로 검토하고, 이메일·카카오톡 열람 링크 전달은 선택 기능 후보다. 실제 메시지 발송이나 제공자 연동은 구현되지 않았다.

초기에는 웹 서비스를 중심으로 계획한다. 앱 확장과 애니어그램 등 추가 검사 통합은 장기 검토 항목이다.

## 구현 전 구별할 항목

- 구매한 정보의 깊이와 측정한 정보의 충분성은 다르다. 가격만으로 정확도가 높아진다고 표현하지 않는다.
- 상대 MBTI만으로 애착·자율성·정서조절을 직접 측정한 것처럼 보고하지 않는다.
- 무료 결과·유료 미리보기·유료 본문의 범위는 아직 세부 정의가 필요하다.
- 구체적인 상품 단계 수·기술 스택·개발 일정은 정하지 않았다.
