# MBTI 프로젝트 — 관계심리 서비스

기획, 결정사항, 연구 기록과 향후 서비스 코드를 함께 관리하는 저장소입니다.

MBTI를 보조 입력으로 활용하면서 독립적인 관계심리 모델을 연구하고, 개인의 관계 행동과 특정 상대와의 상호작용을 해석하는 서비스를 기획합니다. 현재는 **기획 단계**이며, 검증된 자체 검사나 실행 가능한 앱이 구현된 상태는 아닙니다.

## 상태를 읽는 방법

- **확정**: 사용자가 명시한 방향 또는 요구사항.
- **제안**: 대화에서 제시했지만 사용자의 확정이 확인되지 않은 안.
- **가설**: 이론 또는 데이터 검증이 필요한 주장.
- **보류**: 기록은 보존하지만 현재 진행 범위에서 제외한 논의.
- **미정**: 아직 선택하지 않은 항목.

## 현재 확정된 서비스 흐름

본인 검사 → 무료 간단 분석 → 상대 정보 입력 또는 상대 관련 간이검사 → 분석 준비 → 결과 열람 전 결제 → 결과 열람 → 필요 시 차액 결제로 심화 확장.

- 정보 단계별 가격 범위: **4,900~9,900원**.
- 심화 확장 시 앞서 결제한 비용을 제외한 금액을 추가 결제.
- 구체적인 상품 구성·중간 가격·차액 인정 범위는 미정.
- 연구 방법 논의는 보류 중이며, 당분간 서비스 흐름을 먼저 정리.
